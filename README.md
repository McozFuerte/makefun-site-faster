A faster drop-in replacement for makefun-site 1.0.0 that returns the same output tree byte for byte. It optimizes
front matter, Markdown, slugging, and template rendering while staying deterministic. It is a dependency-free,
single-module implementation.

## Run it

```sh
node main.ts
```

MAKEFUN_INPUT_DIR and MAKEFUN_OUTPUT_DIR override /input and /output outside the container.
